# 🍽️ Food Menu Website

A simple and responsive **Food Menu Website** designed as a practice project for my family's food business.

The website showcases different food items through dedicated menu pages and food images, with a clean and user-friendly design.

## 📌 About the Project

This project was created to practice **frontend web development** by building a website around a real-world use case — my family's food business.

It focuses on presenting food products in an attractive and organized manner so that customers can easily explore the available items.

## ✨ Features

* 🍴 Food menu display
* 🖼️ Food item images
* 📄 Multiple menu pages
* 📱 Responsive design
* 🎨 Custom styling and layout
* 🏪 Designed for a real-world family food business
* 🌐 Deployed using GitHub Pages

## 🛠️ Technologies Used

* **HTML5** – Website structure and content
* **CSS3** – Styling, layout, and responsive design
* **Git & GitHub** – Version control and hosting
* **GitHub Pages** – Website deployment
